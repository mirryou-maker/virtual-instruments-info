# Golden Ear: Sound Explorer & Imaginary Instruments — info

Public documentation for **Golden Ear: Sound Explorer** (a free Android ear-training app) and
**Imaginary Instruments** (a free desktop VST3/AU plugin). Both share the same engine: every sound is
computed live from physics, not recorded — some are familiar instruments (bars, strings, tubes), others
are shapes with no real-world equivalent (a donut, two overlapping spheres, a four-dimensional hyperball).

The app and plugin's source code live in a separate, private repository — this repo only holds the
public-facing pages linked from the Play Store listing and from inside the apps themselves.

- [Privacy Policy](privacy-policy.md) — linked from the Play Store listing.
- [Android app guide](android-guide.md) — how to use Golden Ear: Sound Explorer, and where to get the full
  desktop plugin.
- [Plugin guide](plugin-guide.md) — install and usage guide for the Imaginary Instruments VST3/AU plugin,
  including the free/paid SFZ and SF2 sample packs.
