# Golden Ear: Sound Explorer & Imaginary Instruments — info

Public documentation for **Golden Ear: Sound Explorer** (the free Android app) and **Imaginary Instruments**
(the desktop VST3/AU plugin). The app and plugin's source code live in a separate, private repository —
this repo only holds the public-facing pages linked from the Play Store listing and the apps themselves.

- [Privacy Policy](privacy-policy.md) — linked from the Play Store listing.
- [Android app guide](android-guide.md) — how to use Golden Ear: Sound Explorer, and where to get the full
  desktop plugin.
